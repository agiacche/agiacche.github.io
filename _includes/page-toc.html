{% comment %} Compact "On this page" navigation, shared by every page with a handful of named sections (CV, publications, terms). Renders as one native
disclosure, so it needs no JavaScript to open or close and gets keyboard/focus support for free. Below the $large breakpoint it sits inline in the content flow as a small collapsible block (default open, tap the heading to tuck it away) and never narrows the readable text column. At $large and up the same markup instead becomes a small dropdown pinned to the top-right corner of the masthead, clear of the content column entirely (see _sass/layout/_page-toc.scss for why - it used to float inside the content column itself, which crowded the text) - no separate mobile/desktop markup to keep in sync. A tiny optional scroll-driven script highlights whichever section is currently in view (the last heading that has scrolled above a reference line near the top of the viewport - the standard "scrollspy" approach, chosen over IntersectionObserver because the targets are single-line headings rather than tall sections, so a narrow observation band would sit empty most of the time). It's additive only: with JS unavailable the list is still a fully working set of anchor links. Usage: {% include page-toc.html labels=page.toc_sections %} `labels` is a flat array of heading text strings, in the order they appear on the page. Anchor targets are derived with the same `slugify` filter that produces Jekyll heading ids and kramdown auto_ids, so there's no separate id list to keep in sync. {% endcomment %}
